# MVP 백로그 (우선순위 기준)

## Must-have (1차)

- 사용자/조직/권한
  - Owner, Manager, Member 역할
  - 최소 회원 정보 입력(이름, 이메일, 스킬, 가용성)
- 프로젝트/작업
  - 프로젝트 등록, 상태 전환, 예산 공수, 기간
  - 작업 단위 등록, 예정 공수, 완료 상태
- 공수 등록
  - 작업별 배정(사람-작업 매핑)
  - 실제 투입 시간(Time Entry) 등록
- 대시보드
  - 프로젝트 진행률, 완료율, 승인 대기 수, 활성 배정 수
- 승인
  - 배정 요청 승인/반려 상태

## Should-have (2차)

- 대시보드 KPI 보강: 팀별 초과/미배정 경고, 개인별 월 투입 추적
- 변경 이력/audit log
- CSV export
- 휴일/휴가 반영 가능한 사용자 가용성

## Nice-to-have (3차)

- 프로젝트 우선순위 기반 권장 배정
- 다국어 지원
- 알림(이메일/슬랙)
- 비용/정산 리포트
